# Лабораторная работа №1. Библиотеки Python для машинного обучения. Работа с данными

**Вариант:** 1

## О проекте

Проект содержит полный автоматизированный пайплайн по 50 пунктам лабораторной работы. Данные варианта 1 выделяются из общего Excel-файла, очищаются, исследуются статистическими и спектральными методами, масштабируются, преобразуются в тензоры TensorFlow/PyTorch/Keras, используется для PCA-пайплайна и обработки изображений.

- Python: 3.12
- Seed: 42
- Исходный датасет: `data/Lab1_Dataset.xlsx` (локальный файл, не коммитится)
- Вариант 1: 198 наблюдений, признаки `x` и `y`
- Пропуски: одна пустая ячейка в `x`, заполняется средним значением
- Все результаты сохраняются с датой и временем в именах файлов

| Файл | Назначение |
|---|---|
| `main.py` | Единая точка входа: последовательно выполняет все 50 пунктов и сохраняет результаты. |
| `src/io_operations.py` | Чтение/запись `.xlsx`, `.csv`, `.txt`, `.mat`, проверка данных, выделение варианта, обработка пропусков, сохранение изображений. |
| `src/preprocessing.py` | Ручные MinMax/Z-score масштабирования, обратное преобразование, split train/val/test, фиксация seed. |
| `src/data_analysis.py` | Статистика, доверительные интервалы, ковариация/корреляция, критерии SciPy, производные, свёртки, нормы, сравнение scaler-ов. |
| `src/advanced_math.py` | Спектрограммы, периодограммы, Фурье, кубическая и сплайн-интерполяция, бинарные маски, скользящие окна и средние. |
| `src/tensors_pca.py` | TensorFlow/PyTorch/Keras операции, разреженные матрицы, обратная матрица, тензор `F`, PCA-пайплайн. |
| `src/image_processing.py` | Пункт 50: полная обработка цветного изображения средствами SciPy/NumPy. |
| `report.md` | Подробный отчёт с логами выполнения и численными результатами. |

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Для интерактивного выбора стратегии обработки пропусков:

```bash
python main.py --interactive
```

Дополнительные параметры: `--variant`, `--seed`, `--missing-strategy`, `--fill-value`.

## Результаты по заданиям

### Задания 1–3. Чтение и запись данных

Реализованы чтение и запись табличных данных в форматах `.xlsx`, `.csv`, `.txt`, `.mat` с сохранением заголовков. При отсутствии заголовков выполняется автоматическое именование столбцов. Все сохраняемые файлы и изображения получают временную метку `YYYYMMDD_HHMMSS`.

### Задания 4–7. Загрузка датасета и выделение варианта 1

Датасет прочитан в Pandas. Выполнена проверка пустых ячеек, некорректных данных, несовпадения типов и нефинитных значений — обнаружена одна пустая ячейка в `x`. Содержимое таблицы выведено в консоль. Автоматически определены столбцы варианта 1 (`x`, `y`), остальные варианты отброшены, исходный файл не изменяется. Для столбцов явно задан тип `float64`.

### Задания 8–9. Обработка пропусков и NumPy

Реализовано меню стратегий обработки пропусков: удаление строк, приведение типов, заполнение средним, forward/backward fill, нулями или заданным значением. По умолчанию в неинтерактивном режиме используется заполнение средним. После очистки DataFrame конвертирован в массив NumPy формы `(198, 2)`.

### Задания 10–13. Масштабирование, обратное преобразование, split и seed

Реализованы вручную:

- MinMax-нормализация в диапазон `[0, 1]`;
- MinMax-нормализация в произвольный диапазон `[a, b]`;
- Z-score стандартизация.

Параметры масштабирования сохраняются в объектах классов. Обратное преобразование восстанавливает данные с максимальной ошибкой `~1.1e-13`. Массив разбит на `train/val/test` в пропорции `70/15/15`; seed `42` зафиксирован для `random`, NumPy, TensorFlow и PyTorch.

### Задания 14–17. Визуализация и распределения

Построены график исходных данных, нормализованные гистограммы плотности, выведены отсортированные столбцы и построены эмпирические функции распределения.

### Задания 18–21. Описательная статистика и корреляция

Вычислены среднее, дисперсия, медиана и мода средствами NumPy и Pandas. Построены 95% доверительные интервалы для среднего и дисперсии. Рассчитаны ковариационная и корреляционная матрицы. Значимость корреляции проверена через SciPy: `r(x, y) = 0.699052`, `p = 2.30e-30`, связь статистически значима.

### Задания 22–27. Сигнальные и векторные операции

Реализованы взаимная корреляция при сдвигах, численная производная и градиент, свёртка столбцов, скалярное и векторное произведения, L1/L2-нормы. Проверены гипотезы: для `x` гипотеза о равномерном распределении не отвергается (`p = 1.000000`), для `y` гипотеза о нормальности отвергается (`p = 2.80e-05`).

### Задания 28–33. Спектральный анализ, интерполяция и маски

Построены спектрограммы, периодограммы и амплитудно-частотные характеристики через БПФ. Выполнены кубическая интерполяция и интерполяция кубическими сплайнами. Для каждого столбца построены бинарные маски: положительные, отрицательные, нулевые элементы и значения в интервале `[-1, 1]`.

### Задания 34–35. Сравнение с scikit-learn

Ручные MinMax и Z-score преобразования сравнены с `MinMaxScaler` и `StandardScaler`. Прямые преобразования совпадают с точностью до `~1.1e-16`, обратные — до `~1.1e-13`. Построены сравнительные графики и сохранены таблицы ошибок.

### Задания 36–37. Скользящие окна и среднее

Реализованы функции формирования скользящего окна через `sliding_window_view` и вычисления скользящего среднего. Для окон ширины 7 получена матрица `(192, 7)` и построены графики средних.

### Задания 38–42. TensorFlow, PyTorch и операция AXW+B

Сформированы тензоры TensorFlow и PyTorch из исходных данных. Сгенерированы:

- `A` — целочисленный равномерный тензор `(4, 198)`;
- `W` — нормальный тензор `(2, 3)`;
- `B` — непрерывный равномерный тензор `(4, 3)`.

Операция `A × X × W + B` реализована независимо в TensorFlow и PyTorch. Результаты имеют форму `(4, 3)` и совпадают с точностью до `float32`.

### Задания 43–45. Матрицы T, P, Q и выражение в Keras/PyTorch

Сгенерированы три различные матрицы `T`, `P`, `Q` формы `(3, 10)`. В Keras.ops и PyTorch реализована операция:

```text
V = (sin(T) - exp(P)) * Q
```

Результаты имеют форму `(3, 10)` и совпадают с максимальным расхождением `1.192e-07`.

### Задания 46–48. Разреженные и многомерные структуры

Сгенерирована CSR-матрица `100000 × 100000` с `10000` ненулевых элементов; она занимает `0.46 MiB` и не переполняет ОЗУ. Для случайной матрицы `100 × 100` вычислен определитель `8.314713e+77`, найдена обратная матрица с residual `2.878717e-12`.

Многомерный массив `F` формы `(198, 7, 2)` собран из исходных данных, MinMax/Z-score преобразований и четырёх бинарных масок. Использованы срезы-представления NumPy; проверки `np.shares_memory` дают `True`.

### Задание 49. PCA-пайплайн scikit-learn

Построен `Pipeline` из масштабирования и PCA. Перебраны `StandardScaler`/`MinMaxScaler`, шесть наборов признаков из `F` и 1–5 компонент. Лучшая 2D-проекция: набор `original` + `StandardScaler`, `log-likelihood = 4909.0425`, объяснённая дисперсия `1.0000`. Построен график логарифмического правдоподобия.

### Задание 50. Обработка цветного изображения

Для сгенерированного RGB-изображения `320 × 320` выполнены:

1. разделение на каналы `R`, `G`, `B`;
2. поворот на `40°`;
3. преобразование в чёрно-белое изображение;
4. гистограмма яркости;
5. разбиение на 3 изображения по порогам гистограммы `113.1` и `157.9`;
6. алгоритмическая чёрная круглая рамка;
7. добавление гауссовского шума;
8. размытие фильтром Гаусса;
9. повышение резкости (sharpening);
10. PCA RGB-пикселей, реконструкция и 2D-проекция.

Все 17 результатов сохранены в `output/` с временными метками.
